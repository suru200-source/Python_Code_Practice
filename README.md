3.   Project >-- HOSPITALITY_ANALYSIS_AtliQ Hotels: This project analyzes hotel booking data using Python (Pandas, NumPy, and Matplotlib) to understand hotel performance and generate business insights. The analysis follows a complete data analytics workflow, starting from data import and exploration, followed by data cleaning, transformation, visualization, and insight generation.
Project Workflow

3.a. Data Import & Exploration

Imported five datasets containing booking, hotel, room, date, and aggregated booking information.
Explored the datasets by checking their structure, unique values, booking platforms, property IDs, capacities, and booking trends.

3.b. Data Cleaning

Removed invalid records such as negative guest counts.
Detected and handled revenue outliers.
Addressed missing values, particularly customer ratings.
Validated booking capacities to identify inconsistent records.

3.c. Data Transformation

Created a new Occupancy Percentage metric using successful bookings and room capacity.
Merged multiple datasets to enrich the analysis with hotel, room, and date information.

3.d. Data Analysis & Visualization
Generated several business insights, including:

Average occupancy rate by room category.
Occupancy rate by city.
Weekday vs. weekend occupancy comparison.
City-wise occupancy during June.
Revenue realized by city.
Month-wise revenue trends.
Revenue by hotel type.
Average customer ratings by city.
Revenue contribution by booking platform (visualized using a pie chart).
Skills Demonstrated
Data cleaning and preprocessing
Data transformation and feature engineering
Data merging using Pandas
GroupBy aggregation and statistical analysis
Data visualization with Matplotlib
Business insight generation from real-world hotel datasets
Outcome

The project demonstrates how raw hotel booking data can be transformed into meaningful business insights that help management monitor occupancy, evaluate revenue performance, compare cities and hotel types, and identify customer booking patterns for better decision-making.
